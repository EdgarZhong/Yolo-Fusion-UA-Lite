# 框架修正：模态随机失活机制重写与超参修复
> 编码手册 | 2026-03-27 | **优先级：阻塞级——所有后续训练必须在此修复完成后进行**

---

## 一、背景与问题清单

本次修复解决三个独立但同时存在的问题，它们共同导致了新框架训练的模型比原版 M5 低约 1.8 点。

| # | 问题 | 严重性 | 影响 |
|---|------|--------|------|
| P1 | val.py 验证时无条件执行模态 dropout | **致命** | best checkpoint 选择被噪声污染，可能选到次优权重 |
| P2 | 训练脚本 overrides 未设 `erasing=0.0` | **高** | 框架默认 erasing=0.4，全程随机遮挡小目标，cls_loss 系统性偏高 |
| P3 | 模态 dropout 概率语义不直观 | **中** | 用户设 p_rgb=0.2, p_ir=0.2 以为是"60/20/20"，实际是"64/18/18"；需重新设计为直接语义 |

## 二、修复任务

### 任务 1：val.py 彻底移除模态 dropout（P1）

**文件：** `ultralytics-8.2/ultralytics/models/yolo/detect/val.py`

**操作：** 删除 `preprocess` 方法中所有模态 dropout 相关代码块（约行 50-92 之间的 `if hasattr(self.args, 'drop_prob_rgb')...` 整段）。

**原则：** 验证的唯一目的是准确评估模型当前的双模态性能，用于 checkpoint 选择。模态 dropout 是训练正则化手段，不应出现在验证流程中。如将来需要测试单模态鲁棒性，应编写独立的评测脚本，不混入训练验证循环。

**验证方式：** 修改后，在任意训练脚本中设置 `drop_prob_rgb=0.2, drop_prob_ir=0.2`，运行 1 个 epoch，检查验证日志。验证阶段不应出现任何 dropout 相关日志或行为。可以在验证前后打印 `batch["img"]` 的非零通道数来确认。

### 任务 2：train.py 模态 dropout 概率语义重写（P3）

**文件：** `ultralytics-8.2/ultralytics/models/yolo/detect/train.py`

**当前行为（需要替换）：**
```
独立采样 rand_rgb < p_rgb 和 rand_ir < p_ir → 冲突时随机保留一路
p_rgb=0.2, p_ir=0.2 → 实际分布：64% 双模态 / 18% 仅IR / 18% 仅RGB
```

**新行为（直接语义）：**
```
p_rgb 和 p_ir 直接表示该模态被丢弃的最终概率
双模态完整概率 = 1 - p_rgb - p_ir
不允许 p_rgb + p_ir > 1.0
不设全黑选项（全零输入无训练价值）
```

**新实现逻辑（伪代码）：**
```python
def preprocess_batch(self, batch):
    batch["img"] = batch["img"].to(self.device, non_blocking=True).float() / 255

    p_rgb = self.args.drop_prob_rgb
    p_ir = self.args.drop_prob_ir

    # 生命周期控制：最后 close_dropout 轮关闭
    in_dropout_window = (self.epochs - self.epoch) > self.args.close_dropout

    if (p_rgb > 0 or p_ir > 0) and in_dropout_window:
        imgs = batch["img"]
        if imgs.shape[1] == 6:
            B = imgs.shape[0]
            # 参数合法性校验（首次调用时检查一次即可）
            assert p_rgb + p_ir <= 1.0, \
                f"drop_prob_rgb({p_rgb}) + drop_prob_ir({p_ir}) > 1.0"

            # 单次采样直接决定每个样本的模态状态
            # [0, p_rgb) → 丢 RGB
            # [p_rgb, p_rgb + p_ir) → 丢 IR
            # [p_rgb + p_ir, 1.0) → 双模态完整
            rand = torch.rand(B, device=imgs.device)

            mask_drop_rgb = rand < p_rgb
            mask_drop_ir = (rand >= p_rgb) & (rand < p_rgb + p_ir)

            if mask_drop_rgb.any():
                imgs[mask_drop_rgb, 0:3, :, :] = 0.0
            if mask_drop_ir.any():
                imgs[mask_drop_ir, 3:6, :, :] = 0.0

            batch["img"] = imgs

    return batch
```

**概率对照表（验证用）：**

| p_rgb | p_ir | 双模态完整 | 仅 IR | 仅 RGB | 全黑 |
|-------|------|-----------|-------|--------|------|
| 0.10 | 0.10 | 80% | 10% | 10% | 0% |
| 0.20 | 0.20 | 60% | 20% | 20% | 0% |
| 0.15 | 0.10 | 75% | 15% | 10% | 0% |
| 0.0 | 0.0 | 100% | 0% | 0% | 0% |

**验证方式：** 写一个单元测试，构造 B=10000 的假 batch，统计三种状态的实际比例，与上表对比，容差 ±1%。
