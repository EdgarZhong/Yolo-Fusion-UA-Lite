## 3) P3 注意力模块的精确定义

### 命名约定

模块名体现内部结构：`Inception` + 注意力类型 + `Concat`。这些模块不做跨模态融合——两路各自独立经过 Inception → 注意力 → 拼接，和现有 `FeatureAttentionConcat`（Inception + SE + Concat）是同一模式。

### Exp-B：InceptionCoordAttnConcat

**框架内尚未实现，需新增到 `fusion.py`。**

**接口要求（与所有融合模块统一）：**
- 类名：`InceptionCoordAttnConcat`
- 构造函数：`__init__(self, c1: int)`，`c1` 为单模态输入通道数
- 前向输入：`list[Tensor, Tensor]`，两路各 `[B, C, H, W]`
- 前向输出：`[B, 2C, H, W]`

**内部流程：**
```
x_rgb, x_ir = x
fr = CoordAtt(Inception(x_rgb))
fi = CoordAtt(Inception(x_ir))
output = torch.cat([fr, fi], dim=1).contiguous()
```

两路各自独立处理（不跨模态），Inception 复用现有实现。CoordAtt 是新增的子模块。

**CoordAtt 子模块实现规格：**

论文：Hou et al., "Coordinate Attention for Efficient Mobile Network Design", CVPR 2021
官方实现：https://github.com/houqb/CoordAttention/blob/main/mbv2_ca.py

**⚠️ 以下细节已与官方实现交叉验证：**

构造函数参数：`(inp, oup, reduction=32)`。在本项目中 inp == oup == c1。

```python
class CoordAtt(nn.Module):
    def __init__(self, inp, oup, reduction=32):
        super().__init__()
        self.pool_h = nn.AdaptiveAvgPool2d((None, 1))
        self.pool_w = nn.AdaptiveAvgPool2d((1, None))
        mip = max(8, inp // reduction)
        self.conv1 = nn.Conv2d(inp, mip, kernel_size=1, stride=1, padding=0)
        self.bn1 = nn.BatchNorm2d(mip)
        self.act = h_swish()  # 注意：不是 SiLU
        self.conv_h = nn.Conv2d(mip, oup, kernel_size=1, stride=1, padding=0)
        self.conv_w = nn.Conv2d(mip, oup, kernel_size=1, stride=1, padding=0)
```

前向计算：

```python
def forward(self, x):
    identity = x
    n, c, h, w = x.size()
    x_h = self.pool_h(x)                          # [B, C, H, 1]
    x_w = self.pool_w(x).permute(0, 1, 3, 2)      # [B, C, W, 1] → [B, C, W, 1]

    y = torch.cat([x_h, x_w], dim=2)              # [B, C, H+W, 1]
    y = self.act(self.bn1(self.conv1(y)))           # [B, mip, H+W, 1]

    x_h, x_w = torch.split(y, [h, w], dim=2)      # 拆回 H 和 W
    x_w = x_w.permute(0, 1, 3, 2)                 # 恢复 W 维度

    a_h = self.conv_h(x_h).sigmoid()               # [B, C, H, 1]
    a_w = self.conv_w(x_w).sigmoid()               # [B, C, 1, W]

    out = identity * a_h * a_w                     # 广播相乘，得到 [B, C, H, W]
    return out
```

**关键实现细节（与我之前的描述有修正）：**

1. **激活函数是 h_swish，不是 SiLU。** 官方实现使用 h_swish = x * h_sigmoid(x)，其中 h_sigmoid(x) = ReLU6(x + 3) / 6。需要同时实现 `h_sigmoid` 和 `h_swish` 两个辅助类（均约 5 行）。
2. **降维比 reduction = 32**（不是之前写的 16），中间通道数 `mip = max(8, inp // 32)`。对于我们的 P3 层 c1=64（nano），mip = max(8, 64//32) = max(8, 2) = 8。
3. **最终权重是两个一维注意力的逐元素相乘**：`identity * a_h * a_w`，通过广播自动扩展为 [B, C, H, W]。不是加法，也不是拼接后处理。
4. **有 identity 残差连接**：输出 = 输入 × 注意力权重。

### Exp-C：InceptionSimAMConcat

**框架内尚未实现，需新增到 `fusion.py`。**

**接口要求（同上）：**
- 类名：`InceptionSimAMConcat`
- 构造函数：`__init__(self, c1: int)`
- 前向输入/输出同上

**内部流程：**
```
x_rgb, x_ir = x
fr = SimAM(Inception(x_rgb))
fi = SimAM(Inception(x_ir))
output = torch.cat([fr, fi], dim=1).contiguous()
```

**SimAM 子模块实现规格：**

论文：Yang et al., "SimAM: A Simple, Parameter-Free Attention Module for Convolutional Neural Networks", ICML 2021
官方实现：https://github.com/ZjjConan/SimAM

**⚠️ 以下代码与官方 README 一致：**

```python
class SimAM(nn.Module):
    def __init__(self, e_lambda=1e-4):
        super().__init__()
        self.e_lambda = e_lambda

    def forward(self, X):
        n = X.shape[2] * X.shape[3] - 1
        d = (X - X.mean(dim=[2, 3], keepdim=True)).pow(2)
        v = d.sum(dim=[2, 3], keepdim=True) / n
        E_inv = d / (4 * (v + self.e_lambda)) + 0.5
        return X * torch.sigmoid(E_inv)
```

关键点：
- **零可学习参数**，无 BN，无额外层
- `e_lambda = 1e-4`（官方默认值，作为数值稳定项）
- 输出 shape 与输入完全一致
- `keepdim=True` 确保广播正确

### 模块注册

所有新模块（`InceptionCoordAttnConcat`、`InceptionSimAMConcat`，以及子模块 `CoordAtt`、`SimAM`、`h_sigmoid`、`h_swish`）都需要：
1. 在 `fusion.py` 中实现
2. 顶层融合模块在 `__init__.py` 中注册导出
3. 顶层融合模块在 `tasks.py` 的解析逻辑中添加（与 `FeatureAttentionConcat` / `DualConcat` 等同方式）

子模块（`CoordAtt`、`SimAM`、`h_sigmoid`、`h_swish`）不需要注册到 YAML 解析——它们只在顶层模块内部使用。

Inception 输出必须 `.contiguous()`（已有实现已遵守）。

## 6) 门禁与执行顺序

### 前置条件

Exp-B / Exp-C 启动前，必须满足以下全部条件：
1. IR-only COCO 重跑已完成
2. Exp-0 已完成
3. Exp-A 已完成
4. CM-FA 重跑已完成
5. 上述四组结果已完成结论审计（由研究端确认）

Exp-B 和 Exp-C 之间无严格依赖，但建议串行执行（GPU 资源限制），顺序为 Exp-B 先于 Exp-C。

### 门禁 SOP（每个新训练脚本必须执行）

门禁的目的是防止参数控制失效或语义不符（如之前的 freeze 错误），在全量训练前发现问题。

**步骤 1：静态门禁**
```bash
python regression_gate.py --script src/trainning/<脚本名>.py
```
检查项：YAML 可解析、模块已注册、超参值符合预期、路径存在等。

**步骤 2：单 epoch 验证跑**
运行训练脚本，但只跑 1 个完整 epoch 后手动停止（或配置为 1 epoch），产生 `last.pt`。

**步骤 3：动态门禁**
```bash
python regression_gate.py --script src/trainning/<脚本名>.py --dynamic
```
基于步骤 2 产生的 `last.pt` 和训练日志，验证：
- freeze 行为正确（第 1 轮骨干层 requires_grad == False）
- 迁移统计通过硬失败阈值
- loss 数值合理（无 NaN、无异常跳变）

**步骤 4：清理并启动全量训练**
动态门禁通过后，删除步骤 2 产生的 run 目录，然后启动正式的全量训练。
