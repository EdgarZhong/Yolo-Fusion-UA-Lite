### Phase 5：Silhouette Score 实现与运行（必做）

仓库当前没有 silhouette 脚本，需要新建。

创建 `src/diagnostic/analyze/silhouette_score.py`：

```python
"""Silhouette Score 分析脚本
用法：python silhouette_score.py --features <npz> --class-pairs "van:car" ... --output <json>
"""
import argparse, json, time
import numpy as np
from sklearn.metrics import silhouette_score

CLASS_MAP = {"car": 0, "truck": 1, "bus": 2, "van": 3, "freight_car": 4}
MAX_SAMPLES = 5000  # silhouette 在大样本上极慢

def compute_silhouette(features, labels, cls_a, cls_b, seed=42):
    """对指定类别对计算 silhouette score（下采样配平后）"""
    id_a, id_b = CLASS_MAP[cls_a], CLASS_MAP[cls_b]
    mask = np.isin(labels, [id_a, id_b])
    feat, lab = features[mask], labels[mask]
    # 下采样配平
    rng = np.random.RandomState(seed)
    n_min = min(np.sum(lab == id_a), np.sum(lab == id_b))
    n_per_class = min(n_min, MAX_SAMPLES // 2)
    idx_a = rng.choice(np.where(lab == id_a)[0], n_per_class, replace=False)
    idx_b = rng.choice(np.where(lab == id_b)[0], n_per_class, replace=False)
    idx = np.concatenate([idx_a, idx_b])
    return float(silhouette_score(feat[idx], lab[idx])), int(len(idx))

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--features", required=True)
    parser.add_argument("--class-pairs", nargs="+", required=True)
    parser.add_argument("--output", required=True)
    args = parser.parse_args()
    
    d = np.load(args.features, allow_pickle=True)
    labels = d["labels"]
    feat_keys = [k for k in d.keys() if k.startswith("feat_")]
    
    results = []
    for pair_str in args.class_pairs:
        cls_a, cls_b = pair_str.split(":")
        for fk in feat_keys:
            score, n = compute_silhouette(d[fk], labels, cls_a, cls_b)
            results.append({
                "feature_key": fk, "class_pair": pair_str,
                "silhouette": round(score, 6), "n_samples": n
            })
            print(f"  {fk} | {pair_str}: silhouette={score:.4f} (n={n})")
    
    with open(args.output, "w") as f:
        json.dump(results, f, indent=2)
    # 同时写 CSV
    import csv
    csv_path = args.output.replace(".json", ".csv")
    with open(csv_path, "w", newline="") as f:
        w = csv.DictWriter(f, fieldnames=["feature_key","class_pair","silhouette","n_samples"])
        w.writeheader()
        w.writerows(results)
    print(f"Saved: {args.output}, {csv_path}")

if __name__ == "__main__":
    main()
```

### Phase 6：Exp-B / Exp-C 注意力权重近似提取（尽最大努力）

**必须尝试。** 允许多次调试，不用担心 token 消耗。

**方法：** 对 CoordAttn / SimAM 模块注册输入和输出 hook，用 `attn_approx = output / (input + 1e-7)` 近似注意力权重。

**实现方案（任选其一）：**

**方案 A（修改 hook 配置 + 提取脚本）：** 如果提取脚本支持注册 forward hook 捕获输入+输出并计算商，最简单。

**方案 B（独立脚本）：** 写一个小脚本，加载模型和 npz，对 npz 中所有图像重新跑一次前向（只过 P3 融合模块），在 forward hook 中计算近似权重并存储。这需要 GPU 但只跑 layer 23 一步，很快。

**方案 C（最简近似）：** 利用已有的 `feat_pre_attn_rgb` / `feat_pre_attn_ir`（Inception 输出）和融合模块的输出关系。对于 Exp-B (CoordAttn)：注意力作用于 Inception 输出上，Concat 后进 C2f。如果能从 npz 中提取 Inception 输出和注意力后的中间结果，就能算近似权重。具体地说：

```
Exp-B forward: x_rgb → inc_rgb → ca_rgb → concat → C2f → fused_p3
```

`feat_pre_attn_rgb` 是 `inc_rgb` 的输出（注意力前），如果我们再注册一个 hook 在 `ca_rgb` 输出端（注意力后、Concat 前），就能得到 `feat_post_attn_rgb`，然后 `attn_approx = feat_post_attn_rgb / (feat_pre_attn_rgb + 1e-7)`。

**如果这需要给提取脚本加一个新的 hook 点（`post_attn_rgb` / `post_attn_ir`），那就加。** 这是最准确的方式。具体操作：

1. 在 Exp-B/C 的 hook YAML 中新增：
   ```yaml
   post_attn_rgb: {module_path: "model.23.ca_rgb", capture: "output"}  # Exp-B
   post_attn_ir:  {module_path: "model.23.ca_ir", capture: "output"}
   ```
   （Exp-C 对应 `model.23.sa_rgb` / `model.23.sa_ir`）

2. 重新对 Exp-B 和 Exp-C 运行提取（只多了两个 hook 点，开销很小）

3. 分析时从 npz 读取 `feat_post_attn_rgb` 和 `feat_pre_attn_rgb`，逐目标计算 RoI 级别的通道注意力近似值

**如果经合理努力（≥3 次尝试），近似法仍产出不可靠结果（大量 NaN、值域 [0,1] 之外超过 10%），在报告中记录尝试过程和失败原因，然后跳过。**

如果近似法成功，对 Exp-B/C 各跑一次类似 SE 分析的 Fisher-attention 相关性（或写一个新的适配脚本），输出到 JSON。

import numpy as np

from sklearn.manifold import TSNE

MODELS = [

CLASS_MAP = {"car": 0, "truck": 1, "bus": 2, "van": 3, "freight_car": 4}
TOTAL_LIMIT = 5000  # 两类合计上限

def make_comparison(class_pair_str, output_path):
    cls_a, cls_b = class_pair_str.split(":")
    id_a, id_b = CLASS_MAP[cls_a], CLASS_MAP[cls_b]
    
    fig, axes = plt.subplots(2, 2, figsize=(14, 12))
    fig.suptitle(f"t-SNE: {cls_a} vs {cls_b} (feat_fused_p3, perplexity=30)", fontsize=14)

        feat_sub, labels_sub = feat[mask], labels[mask]
        
        # 下采样：每类 min(类内总量, TOTAL_LIMIT//2)
        rng = np.random.RandomState(42)
        n_per = min(np.sum(labels_sub == id_a), np.sum(labels_sub == id_b), TOTAL_LIMIT // 2)
        idx_a = rng.choice(np.where(labels_sub == id_a)[0], n_per, replace=False)
        idx_b = rng.choice(np.where(labels_sub == id_b)[0], n_per, replace=False)
        idx = np.concatenate([idx_a, idx_b])
        feat_sub, labels_sub = feat_sub[idx], labels_sub[idx]
        
        tsne = TSNE(n_components=2, perplexity=30, random_state=42, n_iter=1000)
        emb = tsne.fit_transform(feat_sub)
        
        colors = {id_a: "#1f77b4", id_b: "#d62728"}
        for cid, cname in [(id_a, cls_a), (id_b, cls_b)]:
            m = labels_sub == cid
            ax.scatter(emb[m, 0], emb[m, 1], c=colors[cid], s=3, alpha=0.4, label=cname)
        ax.set_title(name, fontsize=13)
        ax.legend(fontsize=10, markerscale=3)
        ax.set_xticks([]); ax.set_yticks([])
    
    plt.tight_layout()
    plt.savefig(output_path, dpi=200, bbox_inches="tight")
    plt.close()
    print(f"Saved: {output_path}")

make_comparison("van:car", "src/diagnostic/outputs/figures/four_model_tsne_van_car.png")
make_comparison("freight_car:truck", "src/diagnostic/outputs/figures/four_model_tsne_fc_truck.png")
